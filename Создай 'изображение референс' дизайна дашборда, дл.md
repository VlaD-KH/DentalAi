Я создал для вас детализированное «изображение референс» (Design Reference Sheet), которое послужит идеальным эталоном для ИИ-агентов при написании кода вашего дашборда.  
Изображение представляет собой не просто скриншот, а **структурированное руководство по дизайну** (Design Spec Sheet).

### **Описание референса**

Это изображение консолидирует всю архитектуру дашборда для **Solo-оператора автономной лаборатории** в единый визуальный стандарт:

> 1. **Центральная Панель Управления (Main Dashboard Area):**  
   * **3D Viewport:** Интерактивное окно с 3D-моделью челюсти (сегментация и FDI-нумерация) и детальным видом препарированного зуба. Показана точная неоновая **Margin Line** (краевая линия с точностью детекции) и полупрозрачная **циркониевая коронка** с наложенной **тепловой картой толщины стенки** (зеленый-желтый-красный).  
   * **Zirconia Disk Nesting (Справа):** Схема 98.5 мм диска с разметкой Multi-layer градиента, где размещены коронки.  
   * **Telemetry & Sensors (Снизу):** Живые датчики ЧПУ фрезера (обороты, износ фрез, G-код), печи синтеризации (температурный график, оставшееся время) и пневмосистемы.  
> 2. **Аннотированные Панели (Design Panels):**  
   * **Слева:** Панели **«MDR-Compliance & Order Flow»**. Очередь заказов от клиник со статусами (в работе, обзор, успех) и индикатором соответствия европейскому регламенту MDR с кнопкой генерации PDF-паспорта.  
   * **Справа:** Панель **«Hardware IoT Monitor»**. Схема сети всех подключенных устройств лаборатории (ЧПУ, печь, принтер, склад) с индикаторами состояния.  
   * **Снизу:** Врезка **«MCP AI Agent Swarm Status»**. Логируемый терминал, показывающий живой поток вызовов агентов MCP (detect\_margin\_line, segment\_dental\_arch).  
> 3. **Руководство по Стайлингу (Style Guide):**  
   * Прямо на изображении приведены аннотации, определяющие **структуру UI**, примеры состояний элементов (Review, Error, Running), полную **палитру цветов** с HEX-кодами, сетку дизайна и используемые шрифты (Интер для интерфейса и Моноширинный для логов).
