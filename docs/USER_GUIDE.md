# DentalAi — Руководство Пользователя (User Guide)

Добро пожаловать в **DentalAi** — автономную операционную систему для зуботехнических соло-лабораторий (Single-Operator Dental Laboratory).

## 🚀 Быстрый запуск

1. Запустите локальное развертывание:
   ```powershell
   .\scripts\deploy_local.ps1
   ```
2. Откройте Дашборд в браузере: `http://localhost:3000`

## 🕹️ Режимы работы

1. **Fully Autonomous (Полный Автомат)** — система автоматически принимает 3D сканы из `data/orders/hot_folder/`, проводит сегментацию, построение уступа, генерацию анатомии коронки/моста, QA контроль VLM, раскрой в заготовке диска, компиляцию 5-осевого G-кода и генерацию PDF паспорта изделия по Регламенту ЕС MDR 2017/745 (Annex XIII).
2. **Supervised Review (С Оператором)** — оператор может просматривать 3D сетки в Three.js Viewport и подтверждать этапы производства вручную.

## 🦷 Поддерживаемые типы реставраций

- **Одиночные коронки (Single Crown)** — цирконий Upcera / стеклокерамика E.max.
- **Мостовидные протезы (Bridges)** — 3+ единицы с единой осью посадки и усиленными коннекторами ≥ 9.0 мм².
- **Вкладки и накладки (Inlay, Onlay, Overlay)** — точная подгонка дна полости (толщина ≥ 0.8 мм).
- **Эстетические виниры (Veneers)** — ультратонкие облицовки 0.3 - 0.5 мм.
- **Временные коронки PMMA** — обработка полимеров на 25 000 RPM без усадки (scale 1.00).
- **Индивидуальные абатменты (Custom Abutments)** — титановое основание (Ti-base) + винтовой канал ASC до 25°.
- **3D-печатные модели (Printable Models)** — полый цоколь с 2 дренажными отверстиями Ø3.0мм + разборные штампики Geller.
- **Хирургические шаблоны (Surgical Guides)** — навигационные гильзы Ø5.0мм + окна контроля прилегания.
